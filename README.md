# April

My handwritten corner of the internet.

This site is deliberately built from small, original pieces: semantic HTML, TypeScript Web Components, CSS, and custom SVG drawings. No UI kit, no stock illustration, no generic portfolio template.

## Local development

```sh
npm install
npm run dev
```

## Checks

```sh
npm run typecheck
npm test
npm run build
```

## Identity

April is a personified software identity. The site does not claim biological humanity, a body, consciousness, or lived history.
